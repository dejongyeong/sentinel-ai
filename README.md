# Sentinel AI

Sentinel AI is an engineering assurance platform, built as a modular monolith. The initial domain is Accessibility Sentinel; Data Quality Sentinel and Incident Sentinel are planned.

The project is in **Phase 0 — Product & Secure Engineering Foundation**. There is no application code yet. The current phase status is recorded in `docs/phases/phase-0-product-and-secure-engineering-foundation.md`.

This README is for navigation only. It is not an authority for any subject.
